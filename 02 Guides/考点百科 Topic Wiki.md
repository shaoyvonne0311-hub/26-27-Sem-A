# CB2203 考点百科 Topic Wiki

> [!abstract] 用法
> 每个 CB2203 任务都链到本页一个小节。CB2203 80 分集中在 **simulation + transport + scheduling**，三块都是「可复制流程」：写变量 → 建目标/约束或填公式 → 读报表 → 写结论句。

## 运输选址 LP（transportation）

**是什么**：把货物从若干 supply 点运到 demand 点的线性规划。决策变量 `x_ij` = 从 i 运到 j 的数量；目标是总运输成本最小。

**考试怎么问**：给成本表、供应量、需求量，要求建模型（决策变量 + 目标函数 + 约束），再用 Solver 求解并读结果。常考 25–30 分的长题。

**三步骨架**
1. 写变量：`x_ij ≥ 0`（单位写清，件/吨），并说明下标含义。
2. 约束：每个 supply 点 Σⱼ x_ij ≤ supply_i；每个 demand 点 Σᵢ x_ij = demand_j（或 ≥）。
3. 目标：`Min Σ c_ij x_ij`；用 Solver（Simplex LP），读 Answer Report 的 binding / not binding。

**坑**：supply/demand 方向写反；不平衡问题（总供应 > 总需求）忘记加 dummy；只写数字不写单位；答案只报目标值不报分配方案。

## 排队仿真（queue simulation）

**是什么**：用随机数模拟到达与服务时间，算出等待、队列长度、利用率。核心是一张表：到达时刻、开始服务、等待、结束服务。

**考试怎么问**：给 interarrival 与 service 的分布区间，用给定随机数跑 10–15 个顾客，求平均等待/最大队列。

**三步骨架**
1. 搭表头：`n / 随机数 / 到达间隔 / 到达时刻 / 服务时长 / 开始 / 等待 / 结束`。
2. 逐行算：`到达时刻 = 上一到达 + 间隔`；`开始 = max(到达, 上一结束)`。
3. 汇总：平均等待、最大队列、利用率 = 忙时 / 总时长，并写一句结论。

**坑**：`开始 = max(...)` 写成 `上一结束`（忘了空闲情况）；随机数区间端点归属（0 算哪一档）；忘记累积时间。

## 报童仿真（newsvendor）

**是什么**：单周期库存，需求随机；订多了剩货成本 Co，订少了缺货成本 Cu。最优订货量由 critical fractile `Cu/(Cu+Co)` 决定。

**考试怎么问**：给需求分布与成本，先算最优量，再用随机数表模拟 10 天，比较利润。

**三步骨架**
1. 算 `F(Q*) = Cu/(Cu+Co)`，查分布表得 Q*。
2. 模拟：每天一个随机需求 → 销量 = min(需求, Q) → 利润 = 收入 − 成本 − 剩货/缺货罚。
3. 汇总平均利润，换一列随机数再跑一次做敏感性。

**坑**：Cu/Co 记反；用需求均值当订货量；模拟时不区分剩货与缺货成本。

## Sensitivity 与影子价格

**是什么**：Sensitivity Report 给出：shadow price（约束右端 +1 单位带来的目标改进）、allowable increase/decrease（该结论有效的范围）、目标系数范围。

**考试怎么问**：给报告截图或数字，问「若 RHS 加 10，目标变多少」「这个结论在什么范围内成立」「哪个系数变了最优解不变」。

**三步骨架**
1. 找对应约束行 → 读 shadow price。
2. 算：`Δ目标 = shadow price × ΔRHS`，先检查落在 allowable 范围内。
3. 超出范围 → 结论失效，需重跑 Solver。

**坑**：把 shadow price 当成「成本」符号搞反；忽略 allowable 范围直接乘；对非 binding 约束也去乘 shadow price（应为 0）。

## 线性规划建模（LP basics）

**是什么**：目标函数 + 约束 + 非负，全部线性。

**三步骨架**：写决策变量 → 写目标（Max/Min）→ 写约束（≤/≥/=，逐条编号）→ Solver：Simplex LP、勾 Assume Non-negative。

**坑**：约束漏掉隐含上限；把比例关系写成非线性；不检查 Solver 是否找到最优解。

## 整数规划与 0-1 变量（integer / binary）

**是什么**：变量只能取整数（`int`）或 0/1（`bin`），用于选址、排班、要不要做。

**考试怎么问**：选址（选/不选）、指派、固定成本。

**三步骨架**
1. 0-1 变量写清含义（`y_i = 1 表示开 i 仓`）。
2. 用 big-M 连接固定成本与产量：`x_i ≤ M y_i`。
3. Solver 加 `int`/`bin` 约束，其余同 LP。

**坑**：忘加整数约束导致小数解；big-M 取值太小（卡死可行域）；目标函数漏固定成本。

## 进度计划与赶工（scheduling / crashing）

**是什么**：活动网络图（activity-on-node），算 ES/EF/LS/LF、slack，找 critical path；赶工（crashing）用加钱换工期。

**考试怎么问**：画网络图、算最早/最迟、标关键路径、算最短工期与最低赶工成本。

**三步骨架**
1. 画图：节点 = 活动 + 工期，箭线 = 先后关系。
2. 前推 ES/EF → 后推 LS/LF → slack = LS − ES；slack = 0 即关键路径。
3. 赶工：每次选「关键路径上、单位赶工成本最低」的活动压 1 天，直到目标工期。

**坑**：ES 取所有前置的 EF 最大值（不是和）；有并行路径时关键路径会转移；赶工后忘重算关键路径。

## NLP（非线性规划）

**是什么**：目标或约束含非线性项（平方、乘积、开方）。Solver 用 GRG Nonlinear，只能保证 local optimum。

**考试怎么问**：给一个非线性目标（如利润 = 价格×需求），求最优价格；或对照目标/约束逐条解释。

**三步骨架**
1. 写变量与目标（明确非线性在哪一项）。
2. 约束逐条列出（含非负与上限）。
3. Solver 选 GRG，多试 2–3 组初值，比较结果是否一致。

**坑**：用 Simplex LP 跑非线性（报错或假解）；只跑一个初值就宣称全局最优；忘写「结果为局部最优」的说明。

## 回归与 ANOVA 读数

**是什么**：Excel Regression 输出 R²、adjusted R²、系数、p 值、ANOVA 表。

**考试怎么问**：给数据跑回归，解释 R²、某个系数含义、p 值是否显著。

**三步骨架**
1. Data Analysis → Regression，勾 Labels。
2. 读三行：`R Square`（解释力）、`Coefficients`（斜率）、`P-value`（<0.05 显著）。
3. 写 3 句结论：模型解释了多少变异 / 每增加 1 单位 y 变多少 / 是否显著。

**坑**：把 R² 当因果；p 值写成 0.5 显著；多元回归系数解释时忘了「控制其他变量」。

## MCQ 读报表（20 题 25 分钟）

**是什么**：MCQ 多数是「读报表/看图选结论」，不是计算。

**三步骨架**：先扫题干关键词（shadow price / binding / critical path / slack）→ 定位报表对应行 → 排除「符号反」「范围外」两个典型错项。

**坑**：看到数字就选；忽略单位（件 vs 千件）；把 not binding 的约束当有效。

## 整卷与批改流程（mock & review）

**是什么**：pp 有两套结构（2021-22：regression / LP+sens / NLP / newsvendor；2023-24：MCQ / transport / queue / scheduling），整卷必须两套都做。

**三步骨架**
1. 2 小时严格计时，先扫全卷，标出「会 / 半会 / 不会」。
2. 批改只标失分类型（建模 / 计算 / 读数 / 结论句）。
3. 第二天重做失分最多的 1 整题 + 2 小问。

**坑**：把整卷拆成练习做；批改只看分数不看步骤；不写结论句丢分。
