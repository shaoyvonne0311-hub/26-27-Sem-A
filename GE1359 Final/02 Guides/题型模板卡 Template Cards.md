# GE1359 题型模板卡 Template Cards

> [!abstract] 用法
> 每题只有 6 个 slot，四年没动过。**先背模板的骨架，再做题目**：每张卡 = 步骤 + 检查项。做题时不许跳步；批改时只标"哪一步错了"，把那一句抄到卡片底部的「踩过的坑」。
> 数据依据：4 份 Past Final（S2024 / 2425A / S2025 / 2526A），Q1–Q6 分值见 [[Finals 2026/GE1359 Final/02 Guides/Exam Focus Map|Exam Focus Map]]。
> 练完一张卡，在 [[Finals 2026/PP Analysis & Priority.xlsx|PP Analysis]] 的 `04 Tracker` 涂一格。

## Q1 · Domain & range（8–10 分）

**步骤**
1. 先写 domain 三条限制：分母 ≠ 0；`sqrt` 内 ≥ 0；`log` 内 > 0（arcsin/arccos 内 ∈ [−1,1]）。
2. 取交集，用区间写；端点开闭要标清楚。
3. range：优先**求导看单调 + 端点值**；或用 y = f(x) 反解 x，看 x 的定义域给出 y 的范围。
4. 复合函数 f(g(x))：domain 要"g 的输出落在 f 的 domain 里"。

**检查项**：端点是否取到？分母零点是否排除？写的是区间还是不等式？

## Q2 · Exact value + general solution（6–15 分）

**必背精确值**
- sin/cos 30°=1/2, √3/2；45°=√2/2；60°=√3/2, 1/2
- tan 22.5° = √2 − 1；tan 67.5° = √2 + 1
- sin 15° = (√6 − √2)/4；cos 15° = (√6 + √2)/4

**三族通解（写错这一条直接丢分）**
| 方程 | 通解 |
|---|---|
| sin θ = sin α | θ = nπ + (−1)ⁿα |
| cos θ = cos α | θ = 2nπ ± α |
| tan θ = tan α | θ = nπ + α |

**R-form**：a sin x + b cos x = R sin(x + φ)，R = √(a²+b²)，tan φ = b/a（φ 落在正确象限）。化成一个 sin 再套上面的族。

**检查项**：n ∈ ℤ 写了吗？角度制/弧度制统一了吗？α 在主值区间吗？

## Q3 · Gaussian elimination（14 分）

**步骤**
1. 写增广矩阵 [A | b]，标出要消的元。
2. 只用三种行变换，目标 row echelon form（阶梯形）。
3. 回代（back substitution）从最后一行往上。
4. 判解：rank(A) = rank([A|b]) = n → 唯一解；= 未知数个数但 < n → 无穷多解（带参数）；rank(A) < rank([A|b]) → 无解。

**检查项**：每一步是否写清楚"哪一行 + 几倍加到哪一行"？参数解有没有写全？

## Q4 · AM-GM + Vieta（8–12 分）

**AM-GM**
- 形式：a₁+…+aₙ ≥ n·(a₁…aₙ)^(1/n)，aᵢ > 0。
- 用它的关键：**凑出定积或定和**，并说明等号条件（各 aᵢ 相等）能不能取到。
- 常见：x + 1/x ≥ 2（x>0）；(a+b)(1/a+1/b) ≥ 4。

**Vieta**
- α+β = −b/a，αβ = c/a。
- 常考变形：α²+β² = (α+β)² − 2αβ；1/α + 1/β = (α+β)/αβ；α³+β³ = (α+β)³ − 3αβ(α+β)。
- 反求方程：x² − (α+β)x + αβ = 0。

**检查项**：正数条件写了吗？等号成立条件验了吗？韦达是"两根"还是"三根"？

## Q5 · Induction + recurrence（8–9 分）

**归纳法模板（三段，缺一段扣分）**
1. **Base**：n = 1（或题给起点）代入，左右相等，写明"成立"。
2. **Assume**：设 n = k 时命题成立，把式子**完整抄一遍**。
3. **Step**：证 n = k+1，从左边出发，**用上 assume 的等式**，化到目标式，最后写"由归纳法，对所有 n ≥ 1 成立"。

**递推→通项**
- 一阶线性 a_{n+1} = p a_n + q：设特解常数 c，c = pc + q，通解 a_n = A p^n + c。
- 二阶线性：特征方程 r² = pr + q，按 Δ 分实根/重根/复根三种写法。
- 求出通项后，题目常要求"用归纳法验证"，两套都要会。

**检查项**：base 是不是真的代入了？k+1 那一步有没有用到假设？

## Q6 · Counting（18–21 分，最大一块）

**决策树**
1. 有没有顺序？有 → permutation；无 → combination。
2. 元素可重复吗？不可重复 → 逐位相乘且每次减 1。
3. 有相同元素吗？→ n!/(n₁!n₂!…)。
4. 出现"至少/至多" → **补集法**（总数 − 反面）。
5. 相邻 → 捆绑法；不相邻 → 插空法；圆桌 → (n−1)!。

**检查项**：算的是排列还是组合？"至少一个"有没有用补集？相同元素除了吗？

## 考场顺序（2 h / 100 分）

1. 先 Q6 counting（20 分，最稳，30 分钟）。
2. 再 Q3 Gauss（14 分，纯机械，25 分钟）。
3. 再 Q2 + Q1（约 20 分，30 分钟）。
4. 最后 Q4 + Q5（约 25 分，30 分钟），剩下 5 分钟只查：n ∈ ℤ、端点、等号条件。
