## Q1 定义域与不等式（DR + INEQ）

**是什么**：domain（定义域）是函数允许的输入集合；range（值域）是输出集合。DR 题先看限制：分母 ≠ 0、偶次根号内 ≥ 0、log 内 > 0、tan 的角 ≠ π/2 + kπ。

**考试怎么问**：给一个含根号/分式/log 的式子，求 domain 或 range；或解不等式写成**区间记号**（`(a, b]`、`[a, b) ∪ (c, ∞)`）。

**三步骨架**
1. 写限制条件（逐条列，不合并）。
2. 解每条不等式 → 取交集。
3. 画数轴验端点：开/闭括号跟「能否取等」一致。

**坑**：把 `≤` 写成 `<`；交集写成并集；漏掉 tan 的排除点；range 题忘记配方后看顶点。

## Q2 精确值（exact value，不用计算器）

**是什么**：把 sin/cos/tan 的特殊角（15°、22.5°、75°、105°…）写成**根式**，如 tan 22.5° = √2 − 1，sin 15° = (√6 − √2)/4。

**考试怎么问**：`Find the exact value of ...`，答案必须是 surd（根式），不能给小数。

**三步骨架**
1. 拆角：22.5° = 45°/2；15° = 45° − 30°；75° = 45° + 30°。
2. 用 half-angle 或 sum/difference 公式，只保留正号（按象限定符号）。
3. 有理化分母，写成最简根式。

**坑**：half-angle 忘选正负号；tan 22.5° 写成 1/(1+√2) 不化简；答案留小数。

## Q2 三角通解（general solution）

**是什么**：三角方程的所有解，写成 family（族）。三族固定写法：
- sin θ = sin α → θ = **nπ + (−1)ⁿ α**
- cos θ = cos α → θ = **2nπ ± α**
- tan θ = tan α → θ = **nπ + α**

**考试怎么问**：`Solve, giving the general solution`；或先化成同名同角再套。

**三步骨架**
1. 化到 `sin θ = k`（k ∈ [−1,1]），先求一个 principal value α。
2. 套上面三族之一（sin 用 (−1)ⁿ，最容易错）。
3. 若角是 2x 或 x + π/3，最后把 θ 反解回 x，并保留 n ∈ ℤ。

**坑**：sin 族写成 `α + nπ`（漏 (−1)ⁿ）；忘记写 n ∈ ℤ；范围题（0 ≤ x < 2π）要把 n 代进去筛解。

## Q2 复合函数（composite / inverse）

**是什么**：f(g(x)) 的 domain 由「g 的输出必须落在 f 的 domain 内」决定；inverse 只对 one-to-one 存在。

**考试怎么问**：给 f、g，求 f∘g 的 domain/range，或求 inverse 并写定义域。

**三步骨架**
1. 先算内层 g 的 range。
2. 让 range(g) ⊆ domain(f)，解不等式。
3. inverse：交换 x/y 后解出 y，再把原 range 写成新 domain。

**坑**：直接把外层 domain 抄成答案；inverse 忘写 domain；忘记排除内层自身限制。

## Q3 高斯消元（Gauss elimination）

**是什么**：把 augmented matrix 用初等行变换化到 row echelon / reduced form，再回代求解。

**考试怎么问**：解线性方程组，并说明**三种情形**：唯一解 / 无限多解（引入自由参数 t）/ 无解（出现 `0 = 非零`）。

**三步骨架**
1. 写 augmented matrix（系数 + 常数列）。
2. 主元向下消元（允许换行，主元尽量取 1）。
3. 回代或化 RREF；判情形：看最后一行 `[0 … 0 | c]`，c ≠ 0 → 无解；有自由列 → 无限解。

**坑**：消元时漏乘整行；情形判断只看行列式（矩形矩阵不适用）；无限解忘写参数式。

## Q4 AM-GM 与 Vieta

**是什么**：AM-GM：对正数 a₁…aₙ，`(a₁+…+aₙ)/n ≥ (a₁…aₙ)^{1/n}`，等号当且仅当全相等。Vieta：方程根的和/积/两两积与系数关系。

**考试怎么问**：证明不等式（求最小值）；或已知根的关系求系数/对称式（如 α² + β²、1/α + 1/β）。

**三步骨架**
1. AM-GM：先确认全为正 → 配成 n 项 → 写出 ≥ → 说明等号条件（这是得分点）。
2. Vieta：写 α+β = −b/a、αβ = c/a。
3. 把要求的对称式用和与积表示（α²+β² = (α+β)² − 2αβ）。

**坑**：没验证「正数」就用 AM-GM；忘写等号成立条件；Vieta 符号错（−b/a）。

## Q5 归纳法与递推

**是什么**：mathematical induction 三段：base（n = 1 成立）→ assumption（设 n = k 成立）→ step（证 n = k+1）。递推（recurrence）是用前项表示后项。

**考试怎么问**：证明 `Σ… = …`、整除性（如 3 | 4ⁿ − 1）、不等式；或给递推式求通项/前几项。

**三步骨架**
1. 写清 P(1) 的具体计算（不能只写「显然」）。
2. 「Assume P(k) is true」原句照写，标明这就是 induction hypothesis。
3. 用假设把 P(k+1) 的式子替换掉一块，再化到目标形式；最后写「By induction, true for all n ≥ 1」。

**坑**：base 从 n = 0 还是 1 弄错；step 里没用上假设（等于没证）；整除题忘记拆项凑出归纳假设那部分。

## Q6 排列组合与计数

**是什么**：permutation（有序）/ combination（无序）/ multiset（重复元素）/ 容斥（inclusion–exclusion）。

**考试怎么问**：排队方案数、选人分组、至少一个、密码/字母排列（含重复字母）。

**三步骨架**
1. 先判断「顺序是否重要」→ P 还是 C。
2. 有重复元素：`n!/(n₁! n₂! …)`。
3. 遇到「at least / at most」用补集：总数 − 反面。

**坑**：分组时忘除组数的阶乘（均分组）；「至少一个」直接硬算导致重复计数；ignoring 相邻限制（捆绑法）。

## 弱势槽：complex roots / sum-to-product

**是什么**：complex roots 指 zⁿ = 1 或二次方程复根；sum-to-product 是把 sin A ± sin B 化成 2 sin((A±B)/2) cos((A∓B)/2)。

**考试怎么问**：求所有复根并画在复平面（角度 2kπ/n）；或把和差化积后解方程/求积分。

**三步骨架**
1. 复根：写 r(cos θ + i sin θ)，θ = (θ₀ + 2kπ)/n，k = 0…n−1。
2. 和差化积：先提出 2，再写半角和半差。
3. 代回原式检验一个值。

**坑**：根的个数少写；角度用度数混弧度；积化和差符号错。

## 精确值速算（10 分钟 5 题）

**是什么**：考场前热身用的固定训练：只做 15°/22.5°/75° 三类，目标是 90 秒一题且全对。

**三步骨架**
1. 先写三类公式卡（不看）。
2. 5 题限时 10 分钟。
3. 只改错的那一步，不重做整题。

## 整卷与批改流程（mock & review）

**是什么**：4 份 Past Final，每份 6 题 100 分、2 小时。整卷是唯一能校准时间分配的训练。

**考场顺序（固定）**：Q6 → Q3 → Q2/Q1 → Q4/Q5；每题先写骨架再算，卡住超过 6 分钟就跳。

**批改三步**
1. 只标「错在第几步」，不写答案。
2. 同一类错合并成 1 条规则，写进模板卡「踩过的坑」。
3. 第二天只重做错的那 2–3 类，各 2 题。

**坑**：整卷当练习题做（不限时）；批改时看答案觉得「我会了」；错题不隔天重做。

## 公式表与陷阱清单（考前轻回忆）

**是什么**：考场只发一张 trig identities formula sheet；其余公式必须背。

**固定清单（5 条）**
1. sin 通解带 (−1)ⁿ。
2. tan 22.5° = √2 − 1。
3. AM-GM 等号条件必须写。
4. 高斯三种情形要判最后一行。
5. 区间记号开闭跟取等一致。

**做法**：只口述，不刷新题；20 分钟收工。
