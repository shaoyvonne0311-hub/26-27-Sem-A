# CB2203 Data-driven Business Modeling - Course Hub
- **Exam:** Thu 10 Dec, 09:30. 50% of grade. 2 hours, closed book (per course outline).
- **Style (your notes):** MCQs like the assignments, including some reading Excel outputs; long questions similar to assignment/PPT/tutorial examples, including fill-in-the-blank Excel input.
## Topics (outline)
Linear programming 1-2 - LP sensitivity analysis - Integer programming 1-2 - Non-linear programming - Simulation 1-3 (Monte Carlo, newsvendor, queueing, overbooking) - Regression 1-2 (ANOVA table, significance, inference).
Solver applications: investment, inventory, product mix, workforce/project scheduling, assignment, production planning, transportation.
## Approach
Practise every question type with its examples: formulate, Solver, read reports, fill Excel inputs, regression output reading.
